# Hotkeys

^ Dolly's shortcuts work in any app, even when Dolly is hidden, and need no Accessibility permission.

## Defaults

| Action | Shortcut |
|---|---|
| Record / stop (full screen) | [[⌃⌘R]] |
| Record area | [[⌃⇧⌘R]] |
| Record last area again | [[⌃⌥⌘R]] |
| Pause / resume | [[⌃⌘P]] |
| Draw on screen while recording | [[⌃⌘D]] |
| Screenshot screen | [[⌃⌘S]] |
| Screenshot area | [[⌃⌘A]] |
| Screenshot window | [[⌃⌘W]] |

## Changing a shortcut

![Hotkeys settings](/shots/settings-hotkeys.png)

Open **Settings → Hotkeys**, click a field, and press the new combination. It must include ⌘, ⌃ or ⌥ so it cannot block ordinary typing. [[Esc]] cancels. While a field is listening, Dolly's own shortcuts are paused so you can re-assign a combination that is already in use.

A field turns **orange** when macOS or another app owns that shortcut (for example ⇧⌘3, ⇧⌘4, ⇧⌘5 or ⌘Space) — pick another. The ↺ button restores one default; *Reset all shortcuts to defaults* restores all eight.
